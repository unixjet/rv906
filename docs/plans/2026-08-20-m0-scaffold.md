                    $(wildcard rtl/*.sv) $(wildcard rtl/*.v))

## Task 8: Run the smoke test end to end

- [ ] **Step 8.1: Run**

```bash
cd $RV906
timeout 30 bin/verisim/testbench --print-result test/smoke/smoke.out; echo "exit=$?"
```

`--print-result` is mandatory: the `PASS.`/`FAIL. test no.` messages in `TestBench::run` are gated on this flag — without it a successful run prints nothing. Expected: output contains `PASS` and the run terminates well before the timeout. Expected exit code: `exit=1` — the process returns the **raw tohost value**, and tohost==1 IS the pass encoding. Do not "fix" this; record the convention in `docs/08-verification.md` (Task 10).

If it hangs (timeout): the on-chip watchdog converts read-path stalls into `FAIL. test no. = 1` after 8192 cycles, so a full timeout means the WRITE path is stalled (crossbar/MEMCTL side). Debug order — (1) rerun with waves if available, else (2) add a temporary `printf` of `mpin->cs/addr` in `TB::step` to confirm memory traffic, (3) add `--trace` to `VERISIM_FLAGS` and dump FST to check TestMaster's state. If the CLINT read (`S_C_ADDR`/`S_C_DATA`) is the blocker, drop those two states from `TestMaster.v` (go straight W→R→T), note the width-adapter issue in `docs/08-verification.md` as an M6 to-do, and re-run — the memory path is M0's hard requirement, CLINT access is best-effort.
