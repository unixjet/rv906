## §A. The MMU cluster (`mmu/rtl/`)

### §A.1 aq_mmu_top.v — ports and protocols

Port groups (`:17-152`):
- IFU: `ifu_mmu_va[51:0]`, `_va_vld`, `_abort` in (`:108-110`);
  `mmu_ifu_pa[27:0]`, `_pa_vld`, `_access_fault`, `_prot[4:0]` out
  (`:132-135`). **No IFU page_fault pin** — fetch page fault rides
  prot[4]. prot encoding `{pgflt, smode, ca, buf, sec}`
  (aq_mmu_utlb_top.v:370-372).
- LSU: `lsu_mmu_va[51:0]`, `_va_vld`, `_abort`, `_st_inst`,
  `_priv_mode[1:0]` in (`:111-118`); `mmu_lsu_pa[27:0]`, `_pa_vld`,
  `_page_fault`, `_access_fault` + PMA `so/ca/buf/sh/sec` out (`:136-147`).
- PTW memory (borrowed LSU path): `mmu_lsu_data_req`,
  `mmu_lsu_data_req_addr[39:0]`, `_size` out; `lsu_mmu_data[63:0]`,
  `_vld`, `_bus_error` in (`:112-114,139-141`).
- CSR/cp0: `cp0_mmu_addr[11:0]`, `cp0_mmu_wreg`, `cp0_mmu_wdata[63:0]`
  (0x9C0-9C3 writes), `cp0_mmu_satp_data/_wen`, `cp0_mmu_mxr/_sum/_maee/
  _ptw_en` in (`:87-94`); `mmu_cp0_cmplt`, `mmu_cp0_data`,
  `mmu_cp0_tlb_inv_done` out (`:125-127`).
- TLB invalidate from cp0: `cp0_mmu_tlb_all_inv/_asid_all_inv/
  _va_all_inv/_va_asid_inv`, `cp0_mmu_tlb_asid[15:0]`,
  `cp0_mmu_tlb_va[26:0]` (`:96-101`).
- PMP: `mmu_pmp_pa[27:0]`, `_chk1`, `_priv_mode[1:0]` out;
  `pmp_mmu_flg[3:0]`, `_hit_num[15:0]`, `_napot_cross` in (`:120-122,
  148-150`).
- `cp0_yy_priv_mode[1:0]` (`:104`), `mmu_xx_mmu_en` (`:151`).

**Handshake**: valid/pa_vld. Same-cycle PA on TLB HIT (combinational,
aq_mmu_utlb.v:771-777,1044); pa_vld held low on miss while the requester
keeps va_vld asserted (IFU: aq_ifu_icache.v:749-757 — icache_rd_vld clears
only on pa_vld/direct/abort; LSU: aq_lsu_ag.v:1053-1056 `ag_pipe_tlb_miss
= ag_pipe_mmu_req && !mmu_pa_vld` → `ag_self_stall`). Faults arrive WITH
pa_vld. abort cancels the outstanding refill (uTLB ABT state,
aq_mmu_utlb.v:904-978).

**rv906 check**: ICache.v already implements the requester side
(icache_stall logic :235,242,251; request-hold flop :253-260); LSU.v
does not (mmu_lsu_pa_vld unconsumed — the M4 AG wait-state task).

### §A.2 aq_mmu_regs.v — satp and the T-Head MMU CSRs

- satp 0x180 (aq_cp0_prtc_csr.v): layout `|63:60 Mode|59:44 ASID|43:28
  rsvd|27:0 PPN|` (`:129-158`); **only mode bit63 writable**: `satp_mode
  <= {wdata[63],3'b0}` (`:139-140`) → Mode ∈ {0=Bare, 8=Sv39}. satp write
  drives `cp0_mmu_satp_wen` (`:179`) which flushes the uTLBs.
- `regs_mmu_en = (satp_mode == Sv39)` (`:636`); `mmu_xx_mmu_en = Sv39 &&
  priv != M` (`:638-639`) — M-mode and bare use the mach/identity path,
  still PMP-checked.
- T-Head CSRs SMIR 0x9C0 / SMEL 0x9C1 / SMEH 0x9C2 / SMCIR 0x9C3
  (`:245-252`): MIR index + P/tfatal; MEL entry-low; MEH entry-high (also
  auto-loads rtu_mmu_bad_vpn on MMU traps, `:448-453`); MCIR command bits
  tlbp/tlbr/tlbwi/tlbwr/invasid/invall (`:480-496`), CSR write stalls the
  pipe until mmu_cp0_cmplt (aq_cp0_iui.v:709-711). **rv906 drops this set
  (D-M4-5).**
- MAEE: mxstatus bit21, **reset 1 in C906** (aq_cp0_ext_csr.v:592-646) →
  PMA from PTE[63:59] when on; **rv906 drops MAEE (D-M4-2)** — reset-1
  would make all stock-test pages uncacheable.

### §A.3 jTLB (aq_mmu_jtlb.v) — geometry

64 sets × 2 ways = **128 entries** on SRAM (aq_spsram_64x98 tag /
64x88 data). Tag 48b `{vld, vpn[26:0], asid[15:0], pgs[2:0], g}` + 2 FIFO
age bits (`:344-356,413-415`); data 44b `{ppn[27:0], flg[15:0]}`;
flg = {L,X,W,R, M(pmp-mach), SO,C,B,SH,SEC, U,X,W,R, V}. Set index from
size-selected VPN slice (`arb_va_index[8:0] = vpn[8:0] | vpn[17:9] |
vpn[26:18]`, aq_mmu_arb.v:527-529). 2-way compare with ASID/G/noasid
qualify (`:522-535`); multi-hit → page fault (`:769-771,787-789`).
Replacement: per-page-size rotating FIFO (`:574-585,615`). Write sources:
PTW refill + tlboper; invalidate = zeroed-tag writes walked by counter.

### §A.4 uTLBs (aq_mmu_utlb.v)

2 × 10-entry fully-associative (`ENTRY_NUM=10`, `:310`), PLRU
(aq_mmu_plru), **no ASID in entries** (match satp ASID,
aq_mmu_utlb_entry.v:127-135). Entry = {V, VPN(28), PGS(3), PPN(28),
FLG(15)}; flag layout documented `:740-745`. Same-cycle hit; refill FSM
IDLE/WFG/WFC/ABT (+fault park, `:904-978`); invalidated on ANY satp write
+ tlboper + VA-indexed (aq_mmu_utlb_entry.v:163-170). On miss the arb
tries jTLB at 4K→2M→1G before PTW (aq_mmu_arb.v:407-476). Permission
check on hit `:740-764` (V, W-without-R, R/W/X per type + MXR, SUM/U
rules); deny `:788-802` (refill access fault, SO-fetch, PMP L/X/W/R with
M-mode L-bypass).

**rv906 simplification (D-M4-4)**: one 128-entry FA flop TLB, one lookup
per port per cycle.

### §A.5 PTW (aq_mmu_ptw.v)

20-state FSM (`:305-324`): PTW_IDLE, PTW_{FST,SCD,THD}_{PMP,DATA,CHK},
PTW_ACC_FLT, PTW_PGE_FLT, PTW_DATA_VLD, PTW_ABT_DATA, PTW_ABT,
PTW_MACH_PMP, PTW_{1G,2M}_PMP1/PMP2. Single outstanding (starts only from
PTW_IDLE, `:383-392`). **No private bus**: `mmu_lsu_data_req/_addr/_size=1`
(8-byte read, `:770-772`) serviced by LSU's aq_lsu_mcic.

PTE addresses (`:626-637`):
```
fst = {regs_ptw_satp_ppn, vpn[26:18], 3'b0}
scd = {lsu_mmu_data[PPN+9:10], vpn[17:9], 3'b0}
thd = {lsu_mmu_data[PPN+9:10], vpn[8:0], 3'b0}
```
(PTE ppn = PTE bits[37:10].)

Page-fault predicate (`ptw_page_flt`, `:689-705`): !V; W-without-R
(`!(R || MXR&X) && W`); S-mode→U-page without SUM; U-mode→non-U-page;
**A=0 faults** (`:698`); **D check COMMENTED OUT** (`:699-700` —
`// || !ptw_flg[6] && ptw_store_type // D bit volation`); superpage
misalignment (`ptw_hit_1g && data[27:10]!=0`, `ptw_hit_2m &&
data[18:10]!=0`); leaf-with-neither-R-nor-X at level 3. Superpage
detection `ptw_hit_1g = chk_fst && V && (R||X)`, `ptw_hit_2m = chk_scd &&
V && (R||X)` (`:642-643`).

PMP deny (`:650-655`): fetch needs flg[2](X), load flg[0](R), store
flg[1](W); **M-mode bypasses unless flg[3](L) set**. Deny → PTW_ACC_FLT →
`ptw_ref_acc_err` (`:716`). PMA: `ptw_ref_pma = maee && !pmp_mach ?
lsu_data_flop[63:59] : sysmap_mmu_flg` (`:719-720`).

Refill output (`PTW_DATA_VLD` with arb grant): jTLB write `{1'b1, ref_vpn,
asid, pgs, g}` / `{ref_ppn, ref_flg}` with flg = {pmp[3:0], pma[4:0],
PTE[7:6], PTE[4:0]} (`:793-803`), plus uTLB refill. Abort drain via
PTW_ABT/ABT_DATA when tlboper preempts (`tlboper_ptw_abort =
arb_tlboper_grant`, aq_mmu_tlboper.v:1081).

M-mode/bare path: mach-tagged entries + PTW_MACH_PMP one-cycle identity
(`ptw_ref_ppn = ptw_req_addr`, `:598-599,726-727`), PMP-checked
(`mmu_pmp_pa = ptw_req_addr[PPN+11:12]`, `:762-764`), PMA from sysmap.

### §A.6 tlboper (aq_mmu_tlboper.v)

Per-operation FSMs: TLBP `:326-328`, TLBR `:386-388`, TLBWI `:446-448`,
TLBWR `:507-510`, INVASID `:578-583` (scans all 128 entries, `:922`),
INVALL `:677-679` (walks 64 indices × both ways, `:921`), INVVA
`:746-759` (probes 4K→2M→1G). Sources: SMCIR writes AND sfence.vma pulses
(`tlb_inv_asid/all/va` qualify `:593,689-691,769-770`); completion
`mmu_cp0_tlb_inv_done` (`:1084`). sfence flavors from cp0
(aq_cp0_rst_ctrl.v:583-586; rs1/rs2 decode `:523-547` — rs1=x0,rs2=x0 →
INVALL).

### §A.8 PTW memory service (aq_lsu_mcic.v)

FSM PTW_IDLE/PTW_REQ_DCACHE/PTW_WAIT_DATA (`:165-228`); the read is
**arbitrated into the dcache pipeline** (`ptw_dcache_req = ptw_req &&
!ptw_frz && !dcache_req_mask && icc_xx_idle`, `:232`) — so PTE reads HIT
IN THE D-CACHE when cacheable, else go to the bus. **Coherence argument
(load-bearing for rv906)**: page tables are written by ordinary cacheable
stores, so a PTE line can be DIRTY in the cache at walk time; a bus-only
walker reads stale PTEs. The walker must probe the cache first. The
eviction race (dirty PTE line just evicted, writeback in flight, bus read
overtakes its own writeback) gates the bus read on the VB drain (rv12
MED-5; rv906 `!vb_vld` gate).

### §A.9 sysmap (aq_mmu_sysmap.v)

8 fixed regions encoded as upper bounds in 4K-page units (sysmap.h:19-41);
flags {SO,C,B,SH,SEC} (bit4..bit0, sysmap.h:17). Per-region compare
`sysmap_comp_hitX = pa[27:0] < SYSMAP_BASE_ADDRX` (`:185-200`), chained
through aq_mmu_sysmap_hit cells, default 5'b10011 (SO+SH+SEC). rv906
keeps its OWN contract-5 PMA table in the same function shape.

## §B. Privilege CSRs (`cp0/rtl/`)

File map: aq_cp0_regs.v = decode + read mux + write enables;
aq_cp0_trap_csr.v = ALL trap/privilege state (mstatus family, delegation,
priv register, interrupt arbitration); aq_cp0_prtc_csr.v = satp (+PMP
read-mux passthrough); aq_cp0_hpcp_csr.v = mcounteren/scounteren;
aq_cp0_info_csr.v = misa/mvendorid/…; aq_cp0_ext_csr.v = mxstatus;
aq_cp0_iui.v = CSR privilege checks + exception-vector encode.

### §B.1 mstatus (aq_cp0_trap_csr.v)

Reset: MPP=11, SPP=1, all else 0; SXL=UXL=2'b10 RO (`:495-501,729-732`).
MPP write WARL: writing 2'b10 forces 2'b00 (`regs_mpp_write_ill`,
`:633,643-644`). Trap entry: MPP←pm, MPIE←MIE, MIE←0 (M path,
`:639-640,673-674,703-704`); SPP←pm[0], SPIE←SIE, SIE←0 (S path,
`:655-656,687-688,717-718`). mret/sret: pm←MPP / {0,SPP}; MPP/SPP←0;
MIE←MPIE then MPIE←1; SIE←SPIE then SPIE←1 (`:607-610,641-642,…`).
MXR/SUM writable from both mstatus and sstatus (`:535-557`). FS→dirty on
FP/CSR use (`:561-586`). SD computed (`:495`).
sstatus = S-view (SD, UXL, MXR, SUM, FS, SPP, SPIE, SIE) (`:742-745`).

### §B.2 pm register and delegation (`:590-631,755-849`)

```
pm_wdata: mret → mpp; sret → {1'b0, sstatus_spp};
          trap && !mdeleg_vld → 2'b11; trap && mdeleg_vld → 2'b01
```
pm flops reset 2'b11 (`:620-628`); broadcast `cp0_yy_priv_mode` (`:1390`).
medeleg: 16-bit, write mask `{w[15],0,w[13:12],2'b0,w[9:0]}` (`:755-757`)
— bits 14/11/10 hardwired 0 (delegable: 0-9,12,13,15).
`medeleg_vld_dp = pm[1]==0 && !expt_int && (vec & edeleg)` (`:796-798`).
mideleg: SSIP/STIP/SEIP (+bit17 T-Head) writable (`:815-838`);
`mideleg_vld_dp = pm[1]==0 && expt_int && (vec & mideleg)` (`:848-849`).

### §B.3 S bank + misc registers

sscratch 0x140 / sepc 0x141 ([63:1], bit0=0) / scause 0x142 / stval
0x143 / stvec 0x105 (BASE=wdata[63:2], MODE=bit0) / scounteren 0x106 —
all captured from the same RTU payloads on DELEGATED traps
(`:1018-1028,1061-1073,1117-1141,1173-1185,967-987`). sie/sip =
mideleg-masked views of mie/mip (`:922-926,1260-1264`); sip writes reach
only delegated pending bits (`:1216-1221`). mip: SSIP/STIP/SEIP writable
regs + RO MEIP/MTIP/MSIP pins (`:1202-1240`).

### §B.4 Trap PC + sfence sequencing

```
regs_tvec   = pm == 2'b11 ? mtvec_value : stvec_value;
regs_trap_pc = regs_intr && regs_tvec[0] ? {tvec[39:2],2'b0} + {vec,2'b0}
                                          : {tvec[39:2],2'b0};
```
(`:1346-1359`). **Timing subtlety**: RTU consumes cp0_rtu_trap_pc one
cycle AFTER retire_trap_vld (aq_rtu_retire.v:993-1001 registers the
chgflw, :1034-1035 samples the PC) — by then pm already holds the NEW
mode, so the M/S tvec mux is correct.
sfence.vma executes in the CP0 fence FSM (FNC_CMMU,
aq_cp0_fence_inst.v:178-182,198; rs1/rs2 flavor decode in
aq_cp0_rst_ctrl.v:523-547, pulses `:583-586`, waits
mmu_cp0_tlb_inv_done `:492-498`), then I-cache invalidate (FNC_IICA —
rv906 drops this half, D-M4-6). Reset also does a full TLB invalidate
(`:269-270`).

### §B.5 CSR privilege checks (aq_cp0_iui.v:602-619)

S-mode access to addr[9:8]==11 → illegal; U-mode access to addr[9:8]!=00
→ illegal; write to RO (addr[11:10]==11) → illegal; S-mode mret illegal;
sret+TSR / wfi+TW / satp-or-sfence+TVM illegal (`:574-584`); U-mode
mret/sret/wfi/sfence illegal. Exception vectors (`:658-673`): 12 inst page
fault, 1 inst access fault, 2 illegal, 11/9/8 ecall M/S/U; LSU vectors
(aq_lsu_ag.v:1396-1416): 6/4 misalign, 15/13 page fault, 7/5 access
fault; breakpoint 3.

### §B.6 Counters (aq_cp0_hpcp_csr.v)

mcounteren 0x306 / scounteren 0x106 (32-bit, `:169-179,205-215`); gate S
and U counter reads (`:266-276` — U needs mcounteren&scounteren).

### §B.7 Debug-trigger CSRs (aq_cp0_regs.v:826-831)

TSELECT/TDATA1-3/TCONTROL at 0x7A0-0x7A5 — rv906 M4 implements them as
real-but-zero-trigger (the breakpoint.S escape hatch, D-M4-5); M7 builds
real triggers.

## §C. PMP (`pmp/rtl/`)

Structure: sibling of the MMU in the donor (aq_top.v:837); rv906 makes
it a child of MMU.v (rv12 P18 seam). Ports (aq_pmp_top.v:15-46): CSR side
`cp0_pmp_addr[11:0]`, `cp0_pmp_wdata[63:0]`, `cp0_pmp_wreg`, readback
`pmp_cp0_data[63:0]`; check side `mmu_pmp_chk1`, `mmu_pmp_pa[27:0]`,
`mmu_pmp_priv_mode[1:0]`; results `pmp_mmu_flg[3:0]`,
`pmp_mmu_hit_num[15:0]`, `pmp_mmu_napot_cross`.

CSR addresses (aq_pmp_top.v:82-99): PMPCFG0 0x3A0, PMPCFG2 0x3A2,
PMPADDR0..15 0x3B0..3BF. 18-way decode (`:101-122`).

**Entry count: 16 address slots, only 8 implemented** (hardcoded):
comp_hit instances 8-15 commented out with `pmp_hit[15:8]=0`
(aq_pmp_acc.v:266-284); pmpcfg2 hardwired zero (aq_pmp_regs.v:409);
pmpaddr8..15 read zero, no flops (`:522-529`).

cfg byte (aq_pmp_regs.v:162-189): fields R=[0], W=[1], X=[2], A=[4:3],
L=[7]; bits[6:5] read zero; per-byte lock freezes the byte; reset all
zero. pmpaddr write gating (`:418`): blocked by own-L and by
next-entry-locked-TOR (spec-compliant). Stored: wdata[37:9] (ADDR_WIDTH=29
— PA[39:11]) (`:424`).

**Readback (aq_pmp_regs.v:429-436) — CONFORMANT for C906**:
`pmpaddrX_low[9:0] = A[1] ? {pmpaddrX_value[0], 9'h1ff} : 10'h0` — NAPOT
reads {stored-bit-9, 9 ones}; OFF/TOR read 0 (stored value retained).
G=10 (4KB at PA=40). **This is exactly what rv64mi-p-pmpaddr probes —
rv906 ports it verbatim (no D-M4-3-style fix needed, unlike rv12/C910).**

Matching (aq_pmp_comp_hit.v): modes 00=OFF, 01=TOR, 10=NA4, 11=NAPOT
(`:75-81`). TOR: subtractor `pa - pmpaddr_x[28:1]`, match = ge_bottom &&
addr < top; ge_upaddr chains to next entry (`:87-93`; chain at
aq_pmp_acc.v:124-131, entry0 bottom=1). NAPOT: masked compare
`(addr_mask & pa) == (addr_mask & pmpaddr_x[28:1])` (`:96`); trailing-ones
decode 29 cases, 4KB→1TB (`:108-143`). **NA4 tied 0** (`:101` —
C906 quirk, D-M4-8 keeps it). napot_cross for huge-page straddle
(`:145-156`).

Permissions (aq_pmp_acc.v): `cp0_mach_mode = priv==2'b11` (`:120`);
lowest-hit priority encode (`:313-331`) → flg = {L,X,W,R}; no-hit default
`mach ? 4'b0111 : 4'b0` (`:289`). Deny equation in the MMU
(aq_mmu_ptw.v:650-655, quoted in §A.5). PMP results cached in TLB entry
flags and re-checked per access at hit (flg layout §A.4).

## §E. Tests (`riscv-tests`)

### §E.1 Suites and counts

- rv64si-p: 7 (csr dirty icache-alias ma_fetch scall wfi sbreak).
- rv64mi-p: 17 (breakpoint csr mcsr illegal ma_fetch ma_addr scall sbreak
  ld/lh/lw/sd/sh/sw-misaligned zicntr instret_overflow pmpaddr).
- v suites: rv64ui-v 54 + rv64um-v 13 + rv64ua-v 19 = 86.
- No -v- variants for si/mi (their Makefrags build only _p_tests).

### §E.2 Per-test semantics (measured at the sources)

- **mcsr**: misa MXL=2, mhartid=0, mimpid/marchid/mvendorid readable,
  mtvec/mepc writable-without-trap.
- **illegal**: .word 0 → vec 2, mtval ∈ {0, inst-word}; MPP writable
  probe; mtvec vectored-bit probe (skips when bit0 reads 0); WFI no-trap
  @TW=0; sstatus SUM/MXR writable; sfence.vma+satp no-trap @TVM=0, TRAP
  @TVM=1; sret no-trap @TSR=0, TRAP @TSR=1.
- **zicntr**: cycle/instret user aliases readable by all four CSR forms
  (RV64 build does NOT probe time).
- **instret_overflow**: `csrwi minstret,0; csrr` reads 0 — write
  suppresses the increment.
- **breakpoint**: tcontrol write may trap (tolerated); tselect/tdata1/
  tdata2 → "unsupported type" skip when zero triggers.
- **dirty**: satp Sv39 over DRAM_BASE; PTE V|U|R|W|X|A (no D); MPRV+MPP=S;
  store with SUM=0 → U-bit page fault; SUM=1 store → HW-sets-D OR
  store-page-fault + software D-set + sfence + retry (both pass);
  then PTE_A|PTE_D visible in memory; superpage PTE with PPN LSBs set →
  fault. **Implication: rv906 must fault on D=0 stores (D-M4-1).**
- **icache-alias**: two VA pages aliasing on va[12]!=pa[12]; fetches must
  be physically correct; remap visible after sfence.vma WITHOUT fence.i
  (physical tags suffice — measured in rv12).
- **ma_fetch**: misaligned fetch targets trap vec 0 when C disabled; with
  C (rv906: misa.C RO-on) they don't trap and the misa.C-toggle probes
  skip.
- **scall/sbreak**: M→U via SPP=0+sret; ecall → cause 8 delegated via
  p-env stvec_handler medeleg {0,3,8,12,13,15}; ebreak → cause 3, sepc =
  the ebreak.
- **wfi**: S-mode, SIE=0, sip.SSIP pending → wfi must NOT halt.
- **ma_addr / misaligned family**: HW success OR trap (mcause misaligned
  or access), mtval = addr or 0, NO partial store writeback.
- **pmpaddr**: CSR WARL protocol only (no access blocking): G=10 probe,
  NAPOT bit G-1 live, OFF bits[G-1:0] read 0 but retained, csrs/csrc fold
  the READ view.
